# website

Next.js marketing sites that stay fast, findable and easy to change.

| Skill | Use it when |
|---|---|
| `site-page` | You add a page, a dynamic route or a section. Reuse components first, thin page, View made of parts, content through services, metadata on every page. |
| `site-seo` | You implement metadata, canonical, hreflang, sitemap, robots (AI crawlers included), JSON-LD and redirects. |
| `site-i18n` | You add a language with next-intl without touching the existing URLs: allowlist per page, message parity test, locale-aware links. |
| `site-quality` | Before launch or after a redesign: Lighthouse on a production build, LCP, CLS, INP fixes, and WCAG 2.1 AA basics. |

For an SEO audit report of a live site, use `seo-audit` from the audits pack. For scroll stories and motion, see the animation pack.

## Habits behind it

- Search `components/` before writing UI. Extend with a variant before creating a new component.
- "Done" is the page in a browser at phone and desktop width, not a green build.
- Slugs, anchors and media URLs that other pages or sites link to are contracts.
- Plain readable copy beats effects: the visitor should know what a page offers within one screen.

## Where it comes from

Our own company site (repo-native content, English and Polish, self-hosted media) and the marketing sites of the products we build.
